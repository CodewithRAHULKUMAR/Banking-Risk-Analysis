This end-to-end project presents a complete analysis of banking client data using SQL, Python, Excel, and Power BI. The raw data was initially stored in a SQL database and imported into Python using mysql.connector, allowing structured querying and efficient data extraction for analysis.

The project aims to explore client demographics, financial behavior, loyalty classification, and risk profiling to generate strategic insights for banking operations. The dataset, also included as Banking.xlsx, contains key fields such as estimated income, fee structures, checking account status, superannuation savings, and business lending activity.

In Python (Banking_analysis.ipynb), we performed univariate, bivariate, and numerical analysis to explore distributions, relationships, and patterns across the dataset. Libraries like Pandas, Matplotlib, and Seaborn were used for data cleaning, transformation, and insightful visualizations. These analyses helped us understand how different variables influence client loyalty, risk levels, and financial engagement.

The findings were then visualized in an interactive Power BI dashboard (Banking_Dashboard.pbix), which provides a business-friendly interface to monitor client segmentation, tenure trends, income distribution, fee structures, and risk classifications.
